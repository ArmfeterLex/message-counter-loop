# Message Counter Loop

Простой цикл на Python от 0 до 5, который выводит количество сообщений только для положительных значений.

## Функциональность

- Цикл от 0 до 5 включительно
- Проверка: если messages_count > 0
- Вывод строки "Новых сообщений: X" для чисел от 1 до 5
- Для 0 ничего не выводится

## Пример работы

Новых сообщений: 1
Новых сообщений: 2
Новых сообщений: 3
Новых сообщений: 4
Новых сообщений: 5

## Куда можно встроить

- В уведомления о новых сообщениях
- В учебные материалы по циклам
- Как пример фильтрации значений в цикле
- В демонстрацию работы range

## Требования

- Python 3.x

## Примечание

Цикл перебирает числа от 0 до 5. Благодаря условию выводится только 5 строк (для 1-5). Для 0 вывода нет.
